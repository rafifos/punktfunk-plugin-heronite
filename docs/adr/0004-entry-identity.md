# Identify library entries by Heronite's metadata key

A provider entry's external id is `<runner>:<appName>`, the same key that Heronite's overlay files use. A host library id therefore reads `heronite:steam:620` or `heronite:sideload:steam_620`. The id stays readable, stays stable across scans, and converts directly back to the runner and app name that `heronite://launch` needs. It also uses the vocabulary of the overlay files and of Punktfunk's `heroic` launch kind. A later change breaks the pins and cached art of every client, so this record exists. The alternative `<runner>_<appName>`, which is Heronite's in-memory library key, was rejected: it reads as one opaque token and it parses less clearly.
