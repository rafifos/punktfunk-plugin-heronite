# Publish as `@rafifos/plugin-heronite`

Punktfunk's runner finds a plugin by its directory name under `<config>/plugins/node_modules`. An unscoped package must start with `punktfunk-plugin-`, and a scoped package must be `@scope/plugin-*`. `@rafifos/punktfunk-plugin-heronite` installs but the runner never finds it, and it reports no error. The package is therefore published as `@rafifos/plugin-heronite`, scoped to the maintainer and installed with `--allow-public-registry`. The manifest `id` stays `heronite`, which the host, the console and the library ids use. Sibling packages in the same scope can use any name, because the `plugin-` rule applies only to the package that the runner starts.
