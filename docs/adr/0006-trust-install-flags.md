# Trust Heronite's install flags; never check game files

A plugin can read `/usr`, its own code and state, the paths in its manifest and the folders that the operator grants. The install folder of a game is not in that set, so `fs.stat` on an executable or a ROM reports "missing" even when the file is there. The scan therefore trusts the `is_installed` flag of Heronite and the executable and ROM paths that Heronite records. It never reads the filesystem to find a game. The result is deliberate: a game that someone deletes outside Heronite still appears until Heronite updates its own state. The alternative is to ask the operator to grant each game folder. That alternative causes a permission prompt for each game and a library that is worse than the launcher it copies.
